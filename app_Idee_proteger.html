2. Le mot de passe de la page

Il protège le code de l'app sur Internet (GitHub Pages est public). Prenez un mot de passe différent du code de l'app (qui, lui, chiffre vos idées) et de celui du Coffre. 10 caractères minimum. Il n'est enregistré nulle part : notez-le.

3. Créer le fichier

Le fichier index.html est téléchargé (dossier Téléchargements). C'est le seul fichier à mettre dans GitHub. Tout se passe dans votre navigateur : rien n'est envoyé nulle part.
